# 依赖安装文档

本文档指导从零搭建并运行本系统。推荐环境：**Windows 10/11**（RPA 浏览器自动化面向 Windows 设计）。

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（64 位） |
| Python | **3.11 或以上**（3.13 已验证） |
| 内存 | 建议 ≥ 8GB（本地模型运行时占用较高） |
| 磁盘 | 建议 ≥ 10GB 可用空间（含模型与浏览器） |
| 浏览器 | Chrome 或 Edge（RPA 自动化宿主） |
| 网络 | 可访问 PyPI、HuggingFace（或配置镜像） |

## 2. 安装 Python

1. 从 <https://www.python.org/downloads/> 下载 Python 3.11+
2. 安装时勾选 **Add Python to PATH**
3. 验证：

```bash
python --version
# 输出 Python 3.11.x 或更高
```

## 3. 创建虚拟环境并安装依赖

在项目根目录执行：

```bash
# 创建虚拟环境
python -m venv venv

# 激活（Windows PowerShell / CMD）
venv\Scripts\activate

# 激活（Linux / macOS，可选）
# source venv/bin/activate

# 升级 pip
python -m pip install -U pip

# 安装依赖
pip install -r requirements.txt
```

网络不佳时使用国内镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 4. 浏览器自动化环境

### 4.1 CloakBrowser（首次运行自动下载）

首次启动浏览器任务时，CloakBrowser 会自动下载其浏览器内核到缓存目录。受限网络环境可提前配置（见 `.env`）：

```env
CLOAKBROWSER_BINARY_PATH=D:\Browsers\CloakBrowser\chrome.exe
CLOAKBROWSER_CACHE_DIR=D:\Browsers\cloakbrowser-cache
```

### 4.2 使用本机 Chrome / Edge（推荐）

留空相关变量时，系统会自动扫描 `Program Files` 等标准路径下的 `chrome.exe` / `msedge.exe`。只有安装在非标准路径时才需要手动指定：

```env
CLOAKBROWSER_BINARY_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
# 兼容别名：BROWSER_EXECUTABLE_PATH
```

> 注意：如遇浏览器启动失败，请先关闭所有已运行的 Chrome 进程后重试。

## 5. 本地模型（离线 RAG）

系统默认**本地模型模式**（`LOCAL_MODEL_ONLY=true`），需提前放置以下模型：

### 5.1 Embedding 模型（必需）

- 模型：`BAAI/bge-small-zh-v1.5`
- 放置路径：`models/embedding/bge-small-zh-v1.5/`

下载方式任选其一：

```bash
# 方式一：huggingface-cli（需可访问 HF 或配置镜像 HF_ENDPOINT=https://hf-mirror.com）
huggingface-cli download BAAI/bge-small-zh-v1.5 --local-dir models/embedding/bge-small-zh-v1.5

# 方式二：ModelScope
# https://modelscope.cn/models/BAAI/bge-small-zh-v1.5 下载后放入上述目录
```

### 5.2 Reranker 模型（可选，缺失自动降级）

- 默认路径：`models/embedding/reranker/bge-reranker-v2-m3`（`src/config/settings.py`）
- 也可在 `.env` 中用 `RERANKER_MODEL_PATH` 指向其他本地重排序模型（如 `bge-reranker-base`）
- 模型不存在时系统自动降级为关键词重排序（`_simple_rerank`），不影响启动

### 5.3 离线开关

模型就位后保持以下配置即可完全离线运行（`.env` 已内置）：

```env
EMBEDDING_LOCAL_FILES_ONLY=true
HF_HUB_OFFLINE=1
TRANSFORMERS_OFFLINE=1
```

## 6. Ollama 本地 LLM（推荐）

系统默认使用 Ollama 作为本地大模型，无需云端 API Key：

1. 下载安装 Ollama：<https://ollama.com/download>
2. 启动服务并拉取模型：

```bash
ollama serve                       # 一般安装后已自启
ollama pull qwen3.5:4b             # 主模型
ollama pull qwen2.5:3b             # 兜底模型
ollama list                        # 确认模型已下载
```

3. 验证服务：<http://localhost:11434>

如需使用云端模型（通义千问/OpenAI/DeepSeek），在 `.env` 中配置对应 API Key 并将 `LLM_PROVIDER` 改为对应提供商即可。

## 7. 环境变量配置

```bash
copy .env.example .env
```

编辑 `.env`，按需修改：

| 变量 | 说明 |
|---|---|
| `SERVER_HOST` / `SERVER_PORT` | 监听地址/端口，默认 `127.0.0.1:8023` |
| `LLM_PROVIDER` | `ollama`（默认）/ `dashscope` / `openai` / `deepseek` |
| `OLLAMA_MODEL` | 本地 LLM 名称 |
| `EMBEDDING_MODEL_NAME` | 嵌入模型名，默认 `BAAI/bge-small-zh-v1.5` |
| `RERANKER_MODEL_PATH` | 重排序模型路径，留空用默认 |
| `CLOAKBROWSER_BINARY_PATH` | 浏览器路径，留空自动探测 |

> 生产部署时请务必修改授权管理相关默认凭据（`HUOKE_LICENSE_ADMIN_PASSWORD`、`SECRET_KEY` 等）。

## 8. 启动验证

```bash
# 方式一：开发模式（热重载，自动打开浏览器）
python start_dev.py

# 方式二：生产/独立模式（自动清理端口与缓存）
python run_app.py

# 方式三：Windows 双击 start.bat（含环境自检）
```

启动成功标志：

```
INFO:     Uvicorn running on http://127.0.0.1:8023 (Press CTRL+C to quit)
```

浏览器访问 <http://127.0.0.1:8023/>，看到「任务发布」页面即安装成功。

## 9. 常见问题

| 问题 | 处理方式 |
|---|---|
| `pip install` 超时 | 使用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 浏览器启动失败 | 关闭所有 Chrome 进程后重试；或指定 `CLOAKBROWSER_BINARY_PATH` |
| 8023 端口被占用 | `start_dev.py` 会自动顺延端口；或修改 `.env` 的 `SERVER_PORT` |
| 模型加载失败 / 反复下载 | 确认模型目录正确且 `HF_HUB_OFFLINE=1`；首次下载可临时关闭离线开关 |
| Ollama 连接失败 | 确认 `ollama serve` 已运行、`OLLAMA_HOST` 正确 |
| 跨机器部署后登录态失效 | 删除 `data/browser_user_data` 目录让系统自动重建（Chrome 登录态含 DPAPI 加密，不可跨机器迁移） |
| 知识库/向量库损坏 | 运行 `python scripts/rebuild_vector_db_zh.py` 全量重建向量库 |
